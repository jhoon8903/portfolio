4. 궤적 예측과 실제 이동
벽 경계 계산 MotorGeometry.DistanceToInnerWall과 CircleCast 모델을 공유하지만 별도의 시뮬레이션이다.
실제 모터에는 관통·지속 무시 목록이 있고, 미리보기는 장애물을 반사한다.
완전 일치 또는 물리 엔진 전역 결정론을 주장하지 않는다.
실제 이동은 스텝당 반복8회, 캐스트 결과 버퍼16개의 제한을 갖는다.

5. 에셋 정리와 Android 빌드
약577MB는 제거한 미사용 프로젝트 에셋의 양이다. 최종 APK 감소량이 아니다.
IL2CPP/ARM64 APK는 Android Studio arm64-v8a 에뮬레이터에서 설치·실행·DI 예외 유무를 확인한 개발 기록이 있다.
물리 Android 기기의 FPS·CPU/GPU·메모리 또는 발열을 측정했다는 주장이 아니다.

6. 코드와 AI 활용
공개 코드 스냅샷은 검토일의 로컬 소스 복사본이다. 과거 측정 당시의 고정 리비전으로 간주하지 않는다.
README에 기록된 AI 활용: Claude Code를 설계 비교, 코드 생성·리팩터, 핫패스 감사, 테스트·헤드리스 검증에 활용.
개발자는 명세·수치·설계 방향·데이터 포맷과 직접 플레이 검증을 담당.
원작 Stage1 재구현 사례이며, 원작 출시·운영 실적으로 표기하지 않는다.

재현 자료 보강: 동일 전투 조건의 Frame Debugger 전후 캡처, Profiler 할당 경로, 실제 Android 기기의 프레임타임.
