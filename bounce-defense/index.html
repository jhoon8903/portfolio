01 / BALL COLLISION충돌 후 남은 이동 거리를 반복 처리합니다.

한 프레임의 이동 중 여러 표면에 닿거나, 관통 중 같은 적을 반복 타격하는 상황을 처리해야 했습니다. KinematicRaycastMotor에서 공 반경을 포함한 CircleCast 결과 중 가장 가까운 접촉을 선택하고, 충돌 이후 남은 거리를 다시 계산했습니다.

남은 거리 계산 → 원형 스윕 캐스트 → 가장 가까운 접촉 → 반사 또는 관통 → 남은 거리 재계산

연속 충돌 처리

속도 × 시간으로 이동 거리를 구하고, 접촉점까지 이동한 거리를 빼 다음 충돌을 계산합니다.

반사

접촉 법선으로 방향을 반사하고 속력을 유지합니다. 접촉면에서 0.01만큼 떨어뜨려 즉시 재접촉하는 상황을 줄였습니다.

히트 중복 방지

현재 스텝의 피격 목록과 비행 중 통과한 콜라이더를 관리해, 관통 중 겹쳐 있는 적을 프레임마다 다시 타격하는 문제를 막았습니다.

반사 분기의 실제 코드 일부

float travel = Mathf.Clamp(wallDist, 0f, remaining);
_position += dir * travel;
remaining -= travel;
_velocity = Vector2.Reflect(_velocity, wallNormal).normalized * _speed;
_position += wallNormal * SkinWidth;

코드 확인: KinematicRaycastMotor.cs · MotorGeometry.cs · TrajectoryPreview.cs

궤적 예측의 범위와 반복 제한

실제 이동과 미리보기는 벽 경계 계산을 공유하는 별도 시뮬레이션입니다. 미리보기는 장애물을 반사하며 관통 볼의 경로까지 완전히 일치시키지는 않았습니다. 실제 모터는 스텝당 최대 8회 반복하고 16개 캐스트 결과 버퍼를 사용합니다.

02 / SKILL PIPELINE스킬 수치와 동작을 분리해 조합합니다.

스킬마다 이동 로직과 데미지 계산을 복제하면 조합이 늘수록 수정 범위가 커집니다. 레벨별 수치는 SkillDefinition 데이터에 두고, 효과는 볼 모듈과 데미지 보정으로 분리했습니다. SkillRuntime은 로드아웃 변경을 구독해 볼 구성과 효과를 갱신합니다.

SkillDefinition → PlayerLoadout → SkillRuntime → 볼 모듈 / 패시브 보정 → DamageResolver

로드아웃 변경 시 갱신 지점

private void Rebuild()
{
    RebuildRoster();
    RebuildModifiers();
    RebuildPassiveControllers();
}

직접 타격은 기본 데미지 → 가산 보정 → 치명타 → 반올림 순서로 계산합니다. 화상·폭발 등 2차 피해는 HitContext의 플래그로 치명타와 전역 보정의 적용 여부를 구분합니다.

기본 데미지 → 가산 보정 → 치명타 × 1.5 → 반올림 · 피해 적용
