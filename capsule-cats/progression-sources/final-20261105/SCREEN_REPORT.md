# 후보 C 신규8시드 대조 마감과 42개 확대 판단

최대 범위는 Stage1–8이다. **추가강화 허용7/8돌파, Stage8 추가강화중단2/8돌파**를 관측했다. 이는 사전 고정한 신규8시드의 결과이며 모집단 성공률이나 최종 출시 밸런스 승인이 아니다. 입력·원장·임포트·복원 검증을 통과해 후보 C를 그대로 유지하고 예정된 나머지42개 허용 여정을 실행한다.

## 무엇을 고정하고 비교했는가

입력 digest: `03ff43c05cefc28c6a24abae07d2c7c9f6c9f7cb76ecd45b5854535abb32e9e5`.

## 왜 확대하는가, 무엇은 확인되지 않았는가

- 5쌍은 허용만 관측 기간 안에 돌파했다. 여러 신규 진입 상태에서 성장 기여가 관측돼, 같은 HP를 더 올리는 대신 고정 후보의 표본을 확대한다.
- 1100806은 양쪽 첫 도전 돌파·Stage8 추가구매0이다. 앞 단계 성장으로 통과한 반례를 유지한다.
- 1100807은 양쪽13회 돌파이며 중단 시간이 약1.62분 짧았다. 모든 상태에서 추가강화가 필수라거나 강화가 해롭다는 인과 주장을 하지 않는다.
- 1100801은 양쪽 관측 한도 내 미돌파다. 이를 영구 실패로 확정하지 않으며, 강화 허용 미돌파도 그대로 보고한다.
- Stage8 완료 무보상 패배는 허용3회·중단11회다. 허용의 전체 Stage1–8 완료패배431회중 무보상4회도 보존했다. 모든 패배가 재화를 주는 구조는 아니다.
- 긴 반복 부담, 사람의 재미·리텐션·D일차 도달과 결제 효과는 이 자동 전투로 확정하지 않았다. 약4시간을 승인된 목표로 취급하지 않는다.

## 검증과 실행 상태

16여정 모두 원장·입력 해시 재계산·임포트·복원 검증PASS다. 여덟 쌍의 Stage1–7 선택 전투/경제/강화 항목(각45/46/63/50/36/51/44/37기록)과 첫Stage8진입 재화·레벨·seed/stageSeed가 일치했다. 이 선택 항목 비교는 전체raw바이트 일치나 정확한 재도전 전투 인과쌍의 증명이 아니다.

마감시 현재 입력 불변·복구marker없음·Editor ready/stopped/not compiling을 확인했다. [현재 입력·Editor상태](screen-close-inputs.json), [상태 원문](screen-close-editor-status.tsv). 비교 차트는 생성 후 범례 겹침을 수정해 다시 시각 검토했다. 부분first1–7 분석은 같은 원본의 부분집합이며 합산하지 않는다.

허용 배치 shell69116, 중단 배치 shell69890은 각각8succeeded·exit0로 종료했다. **tail42 shell15006 실행 시작**, 시드1100809–1100850·같은 earned config/digest·Stage1–8연속·동일 관측 한도다. 기존 출력이 없고 앞8개와 중복되지 않음을 확인했다. 실행manifest를 완료표시용으로 수정하지 않는다. 전체 완료 시 첫8개+나머지42개=50독립시드, 추가중단8개를 포함하면58정책실행이다. 현재50완료가 아니다.

## 재현과 실제 기여

- `verify_screen_controls.py --output <새경로>`가 완료8개 원본을 검증해 비교CSV/JSON을 생성한다. 대조 검증기·테스트는 worker `cohort_aggregation`가 두 파일 범위로 구현했고, 메인이 비결정적 메타데이터 비교 문제를 교정 요청하고 실제 원장으로 검토했다.
- 메인이 `plot_screen_earned.py`, `plot_screen_controls.py`로 차트·데이터시트를 생성하고 시각 검토했다. 플롯 환경은 `/tmp/capsule-portfolio-plots-env/bin/python`이다. 비교 그림은 최종 `controls-analysis/`를 읽는다.
- 실행은 단일 Editor 배치 코드가 처리하며 전투마다 에이전트를 만들지 않았다. 모델 토큰 절감률은 측정하지 않았다.
- 이후50개 통합은 `docs/Simulation/scripts/analyze_fixed_cohort.py`에 `screen-earned.json`과 `tail-earned.json`, `--expected-seed-range 1100801 1100850`을 지정한다. 원본을 복사하거나 재시도 기록을 신규 표본으로 만들지 않는다.

42개 마감과 최종 통합 밸런스 채택은 남아 있다. 현재는 고정 후보의 독립 검증 확대 판단이며 서버 배포는 하지 않았다.
