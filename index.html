03 / Technical case

Wiggle Puzzle — 병목을 수치로 줄였습니다.

3인 팀에서 아키텍처·코어·최적화·SDK를 맡았습니다.출시 후 서비스는 종료됐지만 성능 개선 과정은 코드와 수치로 남겼습니다.

P / Problem

여러 캐릭터의 BFS 경로 계산이 한 프레임에 몰렸습니다.

보드 상태가 바뀔 때 반복되는 경로 탐색이 메인 스레드를 길게 점유해 입력 반응과 프레임 안정성을 해쳤습니다.

A / Action

Jobs+Burst로 전환하고 생성·반납 책임을 고정했습니다.

경로 계산을 Job으로 옮기고, NativeContainer 수명과 Pool 반환 규칙을 인터페이스 경계에서 명확히 했습니다. 할당은 재사용해 줄였습니다.

R / Result

600ms+ → 50ms 이하, 저사양 60fps를 확인했습니다.

Profiler 측정에서 연산 지연을 줄이고, Galaxy A 시리즈·Poco·저전력 모드에서 60fps를 유지했습니다.
