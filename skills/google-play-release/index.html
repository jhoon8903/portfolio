출시 자동화 · Unity Android · Google Play 배포 도구

스토어에 올릴 파일과 제출 상태 확인하기

google-play-release

제작 과제

새 빌드를 올릴 때 초안 저장과 심사 제출이 섞이거나, 응답이 끊긴 업로드를 다시 실행하면 현재 배포 상태를 놓칠 수 있습니다.

맡은 일과 작업 방법

개발자가 앱·트랙·버전과 제출 방식을 정하면, 스킬이 AAB 식별값을 확인하고 배포 단계를 기록하도록 만들었습니다. 해시 불일치, 기존 초안, 응답 지연을 재현하는 테스트도 작성했습니다.

확인한 결과

Google Play 응답을 모의한 오프라인 테스트 8개가 통과했습니다. 파일이 다르면 트랙 갱신 전에 중지하고, 결과가 불분명하면 상태를 확인할 수 있도록 기록을 남깁니다.

결과물

배포 전 확인하는 여덟 가지 동작

2026.11.18 · Google Play API 응답을 모의한 자동 테스트 · 8개 통과

실험 조건확인한 동작
오프라인 계획인증 없이 계획을 확인하며 배포 영수증을 만들지 않는다.
심사 제출이미 심사 중인 변경을 보호하는 설정을 사용한다.
초안 모드심사 제출을 호출하지 않는다.
기존 초안 발견파일 업로드 전에 중지한다.
AAB 해시 불일치트랙을 갱신하기 전에 중지한다.
업로드 응답 시간 초과임의로 재시도하지 않고 결과 미확인 상태를 보존한다.
과거 형식의 API 응답지원 여부를 확인한 뒤 원격 변경 전에 중지한다.
로컬 영수증 쓰기 실패이미 성공한 원격 커밋의 상태를 보존한다.
