제 03장 · AI를 활용한 게임 제작

AI Pipeline Skills

플레이할 수 있는 첫 버전부터
출시 후 업데이트까지.

공의 궤적을 시험하고, 픽셀 포즈를 조립하고, 배포할 빌드를 검사합니다. 참조 이미지·제약·완료 조건을 먼저 적고, AI 출력은 검사할 수 있는 결과물로 받습니다. 무엇을 고칠지는 플레이 결과와 작업 기록을 보고 제가 결정합니다.

제작 파이프라인

작업을 선택하면 적용 사례와 결과물을 볼 수 있습니다.

  1. 프로토타입과 기획

    • 빠른 프로토타이핑플레이 가능한 조작 한 가지
    • 게임 기획직업·등급별 캐릭터 명세
    • BM 설계보상과 상품의 공급 조건

  2. 게임 화면 제작

    • 게임 에셋아이콘 원화와 임포트 결과
    • UI 디자인화면 시안과 배치
    • 픽셀 아트격자와 프레임 정렬
    • 방향별 애니메이션스프라이트시트와 재생 GIF

  3. 밸런스와 QA

    • 성장 밸런스강화 조건별 비교표
    • 스테이지 실험반복 전투 실행 기록
    • 플레이 QA수정 뒤 회귀 검사

  4. 출시와 라이브

    • 출시 자동화배포 도구의 테스트 결과
    • 라이브 업데이트해달스도쿠 운영 기록
