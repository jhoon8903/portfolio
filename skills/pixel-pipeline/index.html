64픽셀 포즈가 시트에서도 같은 위치에 있을까?

pixel-pipeline

제작 과제

캐릭터 포즈를 시트에 묶을 때 한 칸만 밀려도 애니메이션에서 몸이 튑니다. 결과물을 다시 잘라 원본과 대조할 기준이 필요했습니다.

맡은 일과 작업 방법

피격 시트와 클립의 좌표를 기준으로 64×64 셀을 다시 읽었습니다. 각 셀의 불투명 영역과 지속 시간을 기록하고, 개별 원본 PNG의 RGBA 픽셀과 대조했습니다.

확인한 결과

8방향 3포즈, 총 24칸 모두 개별 원본과 픽셀이 일치했습니다. 검사표에는 각 포즈의 시트 좌표와 알파 영역 경계를 남겼습니다.
