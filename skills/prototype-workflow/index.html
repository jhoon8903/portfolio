제작 과제

직선으로 쏜 공과 곡선으로 쏜 공에 중력을 언제 켤지 결정해야 했습니다. 작은 조작 하나를 확인할 때도 씬 설정과 코드 변경이 함께 움직였습니다.

맡은 일과 작업 방법

제가 플레이 중 관찰한 궤적과 유지할 씬 설정을 기록하고, AI에는 발사 모드별 중력 전환과 회귀 검사 작성을 맡겼습니다. 스킬이 요청·결정·구현·검토를 같은 작업 기록에 연결하도록 했습니다.

확인한 결과

직선탄은 장애물에 닿거나 깊이 경계를 넘을 때, 곡선탄은 발사할 때 중력을 켜도록 구현했습니다. 이 변경은 코드와 검사 도구를 확인한 시점까지 기록했고, 플레이 확인 여부도 따로 남겼습니다.

결과물

직선탄과 곡선탄의 중력 전환

Smesh-Fest-PhysX · 2026년 9월 협업 제작 기록 발췌

작업기록한 결정과 결과
플레이 관찰중력을 끄면 직선탄이 의도한 위치로 이동했다. 에디터에서 조정한 발사기와 프리팹 값은 보존하기로 했다.
규칙 확정직선탄은 장애물 직접 충돌과 월드 Z 경계 중 먼저 발생한 시점에 중력을 켠다. 곡선탄은 발사부터 중력을 사용한다.
AI 구현 범위두 발사 모드의 분기, 풀에 공을 돌려줄 때 원래 중력값을 복구하는 처리, 회귀 검사를 연결했다.
검토 기준코드와 검사 도구 변경을 기록했다. 최신 Z 경계 조건의 런타임 확인은 해당 체크포인트에서 후속 작업으로 남았다.
