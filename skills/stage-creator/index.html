제작 과제

수치를 조정하기 전에 실제 전투를 반복 실행하고, 중단 뒤 작업 환경을 안전하게 되돌릴 기준선이 필요했습니다.

맡은 일과 작업 방법

고정 입력과 시드, 복구 절차를 갖춘 실행 흐름을 만들고 단일 Editor에서 직렬로 실행했습니다. 완료 기록과 시도 체크포인트를 나눠 집계했습니다.

확인한 결과

실제 전투 34회를 실행했고, 주 기준 32회에서 첫 시도 성공은 28/32였습니다. 자동 정책으로 측정한 Stage1 기준선입니다.
