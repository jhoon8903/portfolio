제작 과제

홈·상태·먹이·산책 화면의 버튼과 패널을 함께 설계하면서도 각각의 크기와 늘어나는 영역을 정해야 했습니다.

맡은 일과 작업 방법

배경과 패널, 버튼을 개별 에셋으로 분리하고 글자는 별도 레이어로 두었습니다. 같은 에셋을 네 화면에 다시 배치해 구성을 비교했습니다.
