제 01장액션핏 · 2024.01 — 2025.10

팀을 만드는 일

개발자 면접을 보고, 인턴의 첫 게임을 리뷰하고, 기획자가 직접 레벨을 고칠 에디터를 만들었습니다.

이 페이지에서

팀의 출발점면접·온보딩인턴 교육개발팀 운영공통 시스템함께 만든 게임

01.1 / 출발점

개발자가 저 혼자였던 팀

디자이너 1명, 기획자 1명, 개발자 한 명으로 캐주얼 게임을 만들었습니다. 팀이 커지면서 채용과 교육, 라이브 운영, 기술 연구와 개발 전략까지 맡았습니다. 편의점 정리왕을 넘겨준 뒤에도 리팩터링과 최적화를 했고, 다른 사람이 이어받을 수 있도록 공통 시스템과 온보딩 문서를 만들었습니다.

01.2 / 합류

면접과 온보딩

정규직 6명과 계약직 4명을 직접 면접하고 온보딩했습니다. 신입 개발자가 프로젝트에 합류할 때 참고할 개발 파이프라인, UI 가이드, 용어집을 작성했습니다.

개발 지식뿐 아니라 팀에서 쓰는 용어와 작업 순서를 함께 전달했습니다. 비개발 부서와 협업할 때도 같은 용어로 대화할 수 있도록 문서를 정리했습니다.

개발 파이프라인
신규 개발자에게 전달할 개발 절차와 작업 기준
UI 가이드
프로젝트에서 사용하는 UI 개발 기준
용어집
개발자와 비개발 부서가 함께 사용하는 용어

01.3 / 교육

인턴 교육과 프로젝트 리드

교육생 과제를 출제하고, 실제 게임의 소프트런칭을 지도했습니다. 매직캣·캣 점프·캔디 슬라이스 등 참여 타이틀에는 직접 구현한 부분과 교육 리드 역할을 구분해 기록했습니다.

교육생이 맡은 프로젝트도 공통 개발 규칙 안에서 진행할 수 있도록 과제와 코드리뷰를 연결했습니다. 아래 목록은 기존 포트폴리오에서 교육 리드로 표시한 타이틀입니다.

01.4 / 운영

코드리뷰와 업무 기준

코드리뷰, Git-flow, 작업 견적과 개발 파이프라인을 팀의 협업 기준으로 정리했습니다. 게임을 만드는 일과 함께 개발자들의 업무를 관리했습니다.

인원이 늘어나는 동안 각자가 작업 방식과 프로젝트 구조를 다시 추측하지 않도록, 코드와 협업 문서에 기준을 남겼습니다.

01.5 / 개발 기반

저장과 결제는 다음 게임에서도 쓸 수 있게

프로젝트마다 저장, UI, 에셋 로딩, 결제·광고 연동을 다시 만들고 있었습니다. 공통 모듈과 에디터를 만들어 다음 프로젝트와 새로 합류한 개발자가 재사용할 수 있게 정리했습니다.

프로젝트마다 저장·UI·에셋 로딩을 다시 구현

Cloud Save · MVVM UI · Asset Provider

반복되는 기능을 공통 시스템으로 분리해 신규 프로젝트에서 재사용했습니다.

결제·광고 등 SDK 설정을 프로젝트마다 반복

IAP · SDK Installer · Push / PostBox

연동과 설정 작업을 공통 모듈로 정리했습니다.

레벨 수정 작업이 개발자에게 집중

모듈형 레벨 에디터

기획자가 직접 레벨 콘텐츠를 만들 수 있도록 에디터를 제작했습니다.
